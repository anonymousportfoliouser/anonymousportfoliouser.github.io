Selected Projects:

PRISM: Prospect Role Identification & Scouting Model
Basketball Analytics · Multi-Stage Predictive Architecture
Multi-stage draft projection system trained on rolling historical cohorts to predict 5-year professional impact (EPM-based) and rotation probability. Integrates role-aware feature engineering, play-type efficiency splits, contextual production normalization, cross-era percentile scaling, and stability-adjusted priors. Employs pairwise gradient boosting for relative ranking calibration and leakage-controlled training windows to preserve forward validity. Designed to identify structural mispricings between consensus evaluation and long-term impact outcomes.
ELWAY: Team Projection Model
Football Analytics · Probabilistic Forecasting
Quarterback-adjusted Elo-based projection framework incorporating player-level impact estimates, injury simulations, opponent adjustments, and reproducible pipelines for weekly probabilistic forecasts and postseason simulations.
QBERT: Quarterback Rating Model
Play-by-Play Performance Modeling
Context-adjusted quarterback evaluation system built on play-level data, incorporating dropback type, pressure environment, opponent strength, and temporal stabilization techniques to estimate persistent player impact.
Player Tracking System
Computer Vision · Spatial Modeling
Homography-based computer vision pipeline aligning broadcast footage to standardized half-court coordinate systems, enabling spatial feature extraction for defensive versatility, rotation dynamics, and effort-based metrics.
True Rebounding Rate
Possession-Level Impact Modeling
Context-adjusted rebounding metric separating team structure from individual marginal contribution using lineup controls, role modeling, and possession-level tagging.
HUSTLE Index
Composite Defensive Effort Metric
Composite metric leveraging tracking and event data to quantify closeouts, contests, deflections, screen navigation, and non-box-score defensive contributions.
Network Perception Analysis

Structural analysis of perception bias using Friendship Paradox frameworks and degree-distribution modeling.
